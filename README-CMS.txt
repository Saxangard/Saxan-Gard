SVENSKA UITSIKTEN - GRATIS BEHEERSCHERM VIA PAGES CMS

BELANGRIJK: Netlify Drop alleen is niet genoeg voor online bewerken.
Pages CMS werkt met een GitHub-repository. Netlify publiceert automatisch na wijzigingen.

EENMALIG INSTELLEN
1. Maak een gratis GitHub-account op https://github.com.
2. Maak een nieuwe repository (bijv. svenska-utsikten) en upload ALLE bestanden
   uit deze map, inclusief het verborgen bestand .pages.yml.
   Tip Mac: verborgen bestanden tonen met Cmd+Shift+punt.
3. Log in op https://pagescms.org met GitHub en geef toegang tot de repository.
4. Selecteer je repository. Er verschijnen de onderdelen Algemene instellingen,
   Nederlands, Zweeds en Engels.
5. Maak bij https://app.netlify.com een nieuwe site via 'Import an existing project'
   en kies GitHub + deze repository. Build command leeg laten, publish directory '.'
6. Bewerk voortaan foto's, teksten en prijzen op https://pagescms.org.
   Klik op Save; Pages CMS commit naar GitHub, Netlify publiceert automatisch.

LET OP
- Voorbeelden in de site zijn nog geen echte accommodatiegegevens.
- Alle drie talen apart aanpassen; vertalingen worden niet automatisch gemaakt.
- Foto's: JPG/WebP aanbevolen, liefst 1600-2200 px breed en gecomprimeerd.
- Prijzen: schrijf ook de munteenheid in het veld, bijvoorbeeld '5.500 SEK/week'.
- Contactformulier opent de e-mailapp van de bezoeker, geen inbox op de server.
- Gebruik NIET Netlify Drop als je automatisch wilt publiceren vanuit Pages CMS.
- Pages CMS en Netlify Free hebben gebruiksvoorwaarden en limieten.
